## Reproductions and repairs

The mounted fake-R2 tests reproduce revoke during get/body hydration and expiry
during upload. A final byte-delivery check and current-time receipt authority
check preserve the regression cases. Physical R2 objects can remain orphaned
after revocation; they are not made available through a new registry/receipt.

Real D1 exposes its expression-depth limit in the combined receipt predicate.
Two independent CHECK guards in the same atomic batch separate physical source
convergence from current consumed-grant authority; either failure rolls back
the whole batch. The final negative proof revokes the grant with an independent
D1 write after preflight and verifies unchanged registry, receipt, source and
audit counts. No database limit, authority check or platform gate is disabled.

Historical migration proofs still test their original schema heads. Their
pre-privacy fixtures use historical synthetic token rows; current runtime
commands do not gain an absent-schema authorization fallback.

## Remaining activation barriers

Recognized artifact references still have an existence oracle: an unknown ID
can retain opaque handling while an existing hidden ID rejects. This checkpoint
certifies content/access fences, not uniform reference-existence privacy.

notification retries, operations/diagnostics, integrations and coordination
consumers remain stage-three work. Creation/sharing/internal progress and the
complete matrix follow. No stage can activate privacy independently.
