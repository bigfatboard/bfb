# Security policy

BFB is pre-release. Security fixes target the current `main` branch; no released version is supported yet.

Report vulnerabilities privately with a [GitHub security advisory](https://github.com/qdis/bfb/security/advisories/new). Do not open a public issue containing an exploit, credential, customer data, task content, provider transcript, or local path.

Include the affected commit, reproducible steps using synthetic data, impact, and any known mitigation. Never include active secrets. Repository maintainers will acknowledge a report, coordinate validation, and publish disclosure details after a fix is available.
