# Local private artifact delivery proof

`pnpm test:c11:artifact-bytes`, composed once by `pnpm test:c11`, owns this
disposable Worker/D1/R2 harness and the retained mounted artifact suites.
The frozen scope is the human upload reply and local artifact-byte section of
[private task delivery](../../docs/contracts/private-task-delivery.md).

Synthetic browser sessions use the production control routes and external
WorkspaceHub. The artifact wrapper forwards actual native R2 operations and
places independent revocation at the witnessed object/body/receipt await seams.
It is test-only tooling, not a deployed route or authority bypass. Dormant private
policy inserts are fixtures, not available private-create commands.

Six independently collected groups retain the upload/view controls and add a
named Reviewer read recipient using a genuine synthetic cookie and CSRF token.
The restricted-project group removes only the project-access row derived from
the consumed view's canonical task/grant lineage, after actual R2 get and body
awaits. Each wave restores its synthetic project access first. Whole canonical
snapshots prove the task grant, role, epoch, parents and committed history stay
unchanged except for that independently removed project grant; FK checks remain
clean. Denied replies retain one-use consumption, receipt/audit history and R2
objects. This is not a view-parent move policy.

The owning command prints bounded redacted check labels and SQL bounds measured
for artifact-handler prepared/bound statements, not control/Hub setup,
seam-witness or snapshot queries. Each measured statement stays within 100
bindings and 100,000 bytes. It never
persists private bodies, credentials, raw error text or local paths. Committed
receipt/consume history is retained after response denial; failed receipt batches
do not create verified records. Orphan R2 objects are not deleted.

This is local native authority proof, not compiled-browser presentation, live
pilot, deployment, agent-upload reply, execution, natural-expiry or activation
certification. Cursor compatibility and other C11 barriers remain separate.
